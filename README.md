# AI alati

Kratka web stranica o AI alatima za razvoj softvera. Projekt prikazuje početnu stranicu, kviz i AI redatelj dio, uz pregled glavnih alata i osnovne informacije.

## Što stranica ima

- Početna stranica s pregledom projekta i AI alata.
- Kviz za brzo provjeravanje znanja.
- AI redatelj sekciju s video sadržajem.
- Detalje o alatima, autoru i dokumentaciji.

## Slike za ubaciti

| --- | --- | --- |
| Dodati sliku za početnu stranicu | Dodati sliku za kviz | Dodati sliku za AI redatelj dio |

## Pokretanje

```bash
npm install
npm start
```

Stranica se otvara na `http://localhost:3000`.
